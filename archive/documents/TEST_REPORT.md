## 🔧 修复的问题

### 问题 1: 过度重试 (144 次)
**原因**: 嵌入模型不匹配导致相似度计算为 0  
**修复**: 有文档就直接生成，不依赖相似度阈值  
**结果**: 重试次数 144 → 0

### 问题 2: 置信度偏低 (0.2)
**原因**: 相似度权重过高  
**修复**: 置信度 = 文档数量权重 (60%) + 相似度权重 (40%)  
**结果**: 置信度 0.2 → 0.7

### 问题 3: 路由逻辑错误
**原因**: 简单查询被路由到 direct (无检索)  
**修复**: 所有查询都使用检索 (有真实知识库)  
**结果**: 简单查询也能检索到相关文档
