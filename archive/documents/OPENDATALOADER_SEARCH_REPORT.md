## 💡 替代方案建议

如果需要一个现代的数据加载工具，建议考虑：

### 1. **pandas** (通用数据加载)
```bash
pip install pandas
```
- 支持 CSV, Excel, SQL, JSON, Parquet 等
- 活跃维护，社区庞大

### 2. **datasets** (Hugging Face)
```bash
pip install datasets
```
- 支持 1000+ 数据集
- 专为 ML/NLP 设计

### 3. **fsspec** (文件系统规范)
```bash
pip install fsspec
```
- 统一文件系统接口
- 支持本地/S3/GCS/HDFS

### 4. **petl** (ETL 工具)
```bash
pip install petl
```
- 提取、转换、加载
- 轻量级 ETL

### 5. **dask** (并行数据加载)
```bash
pip install dask
```
- 大规模数据处理
- 并行加载
